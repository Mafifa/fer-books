## 📚 Overview

Maff Books is a modern web application that brings @Fe_Guarache's insightful book reviews to life. This platform offers a curated selection of the best books they've read, providing literary enthusiasts with a go-to resource for discovering their next great read.

## ✨ Key Features

- **Curated Book Reviews**: Handpicked selection of top-rated books reviewed by @Fe_Guarache.
- **Seamless Navigation**: Utilizes View Transitions API for smooth, app-like page transitions.
- **Responsive Design**: Optimized for various devices and screen sizes.
- **Performance Optimized**: Built with Astro for fast loading times and efficient rendering.
- **Modern Styling**: Sleek interface designed with Tailwind CSS.

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or later)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/maff-books.git
   cd maff-books
```

2. Install dependencies:

```shellscript
npm install
```


3. Start the development server:

```shellscript
npm run dev
```


4. Open your browser and visit `http://localhost:3000`


## 🛠️ Built With

- [Astro](https://astro.build/) - The web framework for content-driven websites
- [Tailwind CSS](https://tailwindcss.com/) - A utility-first CSS framework
- [TypeScript](https://www.typescriptlang.org/) - Typed superset of JavaScript
- [View Transitions API](https://developer.mozilla.org/en-US/docs/Web/API/View_Transitions_API) - For smooth page transitions


## 📦 Scripts

- `npm run dev` - Start the development server
- `npm run build` - Build the production-ready site
- `npm run preview` - Preview the built site locally
- `npm run astro` - Run Astro commands


## 🌟 Features in Detail

### View Transitions

Maff Books leverages the View Transitions API to create a seamless, app-like experience. As users navigate between book reviews, the content smoothly transitions, maintaining context and enhancing the overall user experience.

### Responsive Design

The website is fully responsive, ensuring a great reading experience on devices of all sizes, from mobile phones to large desktop screens.

### Performance

Built with Astro, Maff Books offers exceptional performance. Static site generation combined with partial hydration ensures fast load times and minimal JavaScript overhead.
